# IRL-VLA：通过奖励世界模型训练视觉-语言-行动策略，实现端到端自动驾驶

> 作者: 黄浴 | 来源: https://zhuanlan.zhihu.com/p/1956846015798818776

---

25年8月来自博世、上海大学和清华大学的论文“IRL-VLA: Training an Vision-Language-Action Policy via Reward World Model for End-to-End Autonomous Driving”。

视觉-语言-动作 (VLA) 模型已在自动驾驶中展现出潜力。然而，两个关键挑战阻碍它们的发展：（1）现有的 VLA 架构通常基于开环设置中的模仿学习，这往往会捕捉数据集中记录的行为，导致性能不理想且受限；（2）闭环训练严重依赖高保真传感器模拟，而域差距和计算效率低下构成了重大障碍。本文 IRL-VLA，一种通过逆强化学习奖励世界模型和自建 VLA 方法进行的新型闭环强化学习。其框架采用三阶段范式：在第一阶段，提出一个 VLA 架构并通过模仿学习预训练 VLA 策略。在第二阶段，通过逆强化学习构建一个轻量级奖励世界模型，以实现高效的闭环奖励计算。为了进一步提升规划性能，最终设计专门的奖励世界模型引导强化学习，并通过近端策略优化 (PPO) 算法有效地平衡安全事故、舒适驾驶和交通效率。本文方法在 NAVSIM v2 端到端驾驶基准测试中取得最佳性能，并在 CVPR2025 自动驾驶挑战赛中获得亚军。

如图 a 所示，模仿学习 VLA 方法借助 VLM 的卓越能力实现卓越的性能，但由于开环框架内的模仿学习倾向于复制数据集中记录的行为，大规模模型的全部潜力仍未得到充分挖掘。这是因为驾驶本质上是一项多目标和多模态任务，其中多模态反映多个最优解的存在，而多目标则需要满足不同的评估标准（例如，避免碰撞、遵守可驾驶区域、遵守交通规则等）。

一种更自然的策略是使模型能够在模拟环境中自主探索，如图 b 所示，从而模仿在现实世界中观察的体验式学习过程。然而，开发一个完全交互式的闭环模拟框架仍然是一项重大的技术挑战：1). Sim2Real 领域差距 2). 巨大的计算开销。

本文中，如图 c 所示，引入一种基于逆强化学习框架的闭环强化学习，该框架采用自建的 VLA 方法，称为 IRL-VLA。利用该框架，设计一个实时奖励世界模型 (RWM)，并通过逆强化学习从多种策略中进行学习。它捕捉驾驶的多模态和多目标本质，同时能够以经济高效的方式扩展到大量现实世界数据，从而规避 Sim2Real 领域的适应性。

问题表述

在自动驾驶中，端到端驾驶基于传感器输入数据 S_sensor（例如多视角摄像头图像或激光雷达/雷达点云）、自我状态 S_ego（自我速度和自我加速度）输出未来轨迹 T_traj 或未来动作 A。

π_policy 是学习的策略，其中轨迹 T_traj 可以表示为当前自车坐标系中的一系列车辆航路点（坐标和航向）P = {p_0, p_1, ..., p_l}，其中每个航路点 p_i 定义为 p_i = (x_i, y_i, θ_i)，其中 (x_i, y_i) 表示二维位置，θ_i 表示航向角。或者，智体动作序列也可以表示为 A = {a_1, a_2, ..., a_l}，其中每个动作 a_i 具有与 p_i 相同的语义。参数 l 表示预测范围，即需要预测的未来步数。

模仿策略学习

视觉语言行动：受具身智能领域双过程理论最新进展的启发，提出一种高效的自动驾驶 VLA 模型，该模型包含三个不同的模块：(1) 用于深度场景理解的语义推理模块；(2) 用于精确几何推理的 3D 推理模块；以及 (3) 用于生成分流驾驶轨迹的统一扩散规划器。

语义推理：如图 d 所示，为了在自动驾驶场景中有效处理和融合多模态信息，提出 VLM 命令引导模块。该模块基于 Senna-VLM 框架构建，该框架利用多图像编码策略和多视图提示机制来实现高效、全面的场景理解。

3D 推理：如图 e 所示，首先使用 BEV 视觉编码器和适配器将多视图图像编码为 BEV 空间中的特征图。然后，利用一组检测 token 和地图 token 从 BEV 特征空间中学习矢量化的地图元素和智体运动信息。

统一扩散规划器：如图 f 所示，为了生成多样化且信息丰富的未来轨迹分布，采用基于扩散的方法，处理带有高斯噪声的锚点提议轨迹，条件扩散模型学习一种强大的去噪机制，能够捕捉未来运动固有的多模态性。

为了增强去噪过程，将丰富的场景语义（例如 BEV token、地图 token 和检测 token ）分层集成到轨迹生成流程中。这确保了模型合成的轨迹符合环境约束。在最后的条件解码步骤之后，使用基于轻量级 MLP 的回归头，从细化的轨迹 token 中重建多模态轨迹。这使得每种模式都能与可行、可解释且符合场景的运动模式保持一致，从而提高真实感并更好地遵守物理约束。

模仿策略学习损失：与其他基于扩散的模仿学习训练策略相同，VLA 解码器 π_θ 将 N_anchor 个噪声锚点轨迹 {τ_i} 作为输入，并预测分类分数 {sˆ_k } 和去噪轨迹 {τˆ^i^_k }，训练目标 L_IL 结合轨迹重建和分类。

逆环境学习

奖励数据收集：为了开发有效的奖励世界模型 (RWM)，一个全面的数据集至关重要。该方法利用自我-伪驾驶指标系统 (EPDMS) [3, 6] 中人为设计的指标，该系统包含九个子评分：无过错碰撞 (NC)、可驾驶区域合规性 (DAC)、驾驶方向合规性 (DDC)、交通信号灯合规性 (TLC)、自我进度 (EP)、碰撞时间 (TTC)、车道保持 (LK)、历史舒适度 (HC) 和扩展舒适度 (EC)，以及一个加权总和评分，记为 EPDMS。将 EC 排除在模型范围之外，因为它需要每个场景进行两次单独的模拟。这些指标提供了对环境和智体交互的详细洞察。然而，单独的模仿数据通常缺乏多样性，因为它们无法完全捕捉不同场景中的各种轨迹。

为了增强分数和轨迹的多样性并确保模型的泛化能力，采用三种策略。首先，记录扩散过程每个时间步的轨迹及其对应的 EPDM 得分。其次，没有使用固定的轨迹集，而是使用 K-均值聚类从人类演示数据中采样多种轨迹模式，K 值的范围从 32 到 8192。第三，在 NAVSIM 数据集中每个场景的模拟过程中应用多个自我姿态，以生成多样化的样本。

奖励世界模型：提出一种奖励世界模型 (RWM)，作为传统模拟器的轻量级、数据驱动的替代方案，它能够通过逆强化学习对自动驾驶系统进行闭环评估，并收集下游驾驶统计数据，例如碰撞率、交通规则合规性和驾驶舒适度。RWM 无需计算密集型模拟器，并通过直接基于真实世界演示建模奖励结构来缩小模拟与现实之间的差距。其架构如上图 (b) 所示，与智体架构相似，使用多视角摄像头信息和智体预测的未来轨迹作为输入。RWM 预测智体在模拟环境中的未来奖励。

RWM 使用基于规则的模拟器，针对给定轨迹，建模得分与环境之间的关系。NAVSIM 模拟器生成三种类型的得分。EP 得分衡量自车沿中心线的行驶进度，范围为 [0, 1]。DAC、TLC、TTC、LK 和 HC 得分为二进制，取值为 {0, 1}，用于评估自车是否遵守预定义的驾驶规则。NC 和 DDC 得分的值为 {0, 0.5, 1}，因为当自车的行为没有错误时，它们的惩罚较少。

轨迹特征是从给定轨迹沿途各路点的 BEV 空间特征中提取的，作为轨迹、周围智体和环境之间相互作用的隐表示。最终奖励 Rˆ 由各个组成部分的加权和计算得出。

奖励世界模型优化：训练奖励世界模型 (RWM) 的目的是最小化预测指标得分与真实指标得分之间的误差。在每个训练步骤中，都会采样一批轨迹及其对应的真实得分，以优化 RWM。训练 RWM 的损失函数定义为：rˆ^i^_m 是第 i 条轨迹的指标 m ∈ NC、DAC、DDC、TLC、EP、TTC、LK、HC 的预测得分，r^i^_m 是模拟器中对应的真实得分。

基于RWM的强化学习

虽然模仿学习提供了强大的基线策略，但它本质上受限于离线演示中的偏差和不完全覆盖。为了克服这些局限性，采用闭环强化学习和RWM来微调VLA策略，如上图c所示。采用近端策略优化（PPO）算法，因为它具有稳定性和样本效率——在使用容易出现近似误差的学习奖励模型进行训练时，这两个特性至关重要。

策略优化：策略优化过程包括从VLA策略中迭代采样轨迹，通过RWM对其进行评估，并更新策略参数以最大化预期累积奖励。通过提供实时奖励反馈，RWM无需进行计算成本高昂的传感器渲染和基于物理的模拟。这使得训练可扩展且高效，使VLA模型能够探索多样化的驾驶场景并优化多目标目标（安全性、效率、交通规则合规性）。用 PPO 来训练带有 RWM 的策略 π_θ，选择 RWM 是因为它在与可能引入近似误差的学习环境交互时具有稳定性和样本效率。

优化过程总结如下：

受基于扩散的规划方法 [19, 22] 的启发，扩散策略 π_θ 可以被视为一个内在的马尔可夫决策过程，它从高斯噪声出发，逐步去噪，从而产生一系列动作。遵循这一范式，生成一组轨迹 T_traj，并记录它们的完整扩散过程。对于单个轨迹，扩散级数定义为 T_traj。

在该框架中，RWM 使用多标准评分系统评估每条轨迹，将舒适度指标（EP、LK、HC）与安全性指标（NC、DAC、DDC、TLC、TTC）相结合。这些指标被汇总为基于 EPDMS 的分数 r_epdms。该分数与关键网络的价值估计相结合，并使用 GAE [24] 计算优势值，即 R_epdms = GAE(r_epdms + v_epdms)。此外，受 [17,25] 的启发，为了提高批次间的稳定性，采用组标准化优势，后续处理步骤涉及推导组标准化优势的值 Aˆ_i。

在扩散过程中，每个条件转换都由高斯策略 [2] π_θ 建模，其中 μ_θ(x_t, t, c) 是模型预测的均值，σ^2^_t I 是固定协方差，c 包括当前车辆状态、语义推理特征、3D 推理特征和导航指令。

受 recogdrive [17] 的启发，该扩散策略下整个轨迹的联合对数似然可以表示为logπ_θ (x_0:T)。对于策略优化，采用基于 PPO 算法的强化学习，其中强化学习损失公式为 L_RL。

通过利用RWM辅助的强化学习，基于扩散的规划器能够通过主动探索生成安全舒适的轨迹，超越简单的模仿，并将认知推理引入框架。最终的策略优化损失将强化学习目标与行为克隆项相结合，以保持稳定性并防止预训练策略发生灾难性遗忘。这种组合损失确保稳定有效的策略优化，并利用RWM引导VLA模型实现最佳驾驶行为。

实施细节

IRL-VLA 模型采用 V2-99 主干网实现，处理分辨率为 256 × 704 的多视角摄像机输入。模仿学习阶段 (IRL-VLA-PT) 使用 AdamW 优化器进行 100 个 epoch 的预训练，学习率为 10^−4^，批量大小为 32。奖励世界模型采用逆强化学习进行训练，对于 EPDMS 中 {0, 1} 范围内的指标，采用二元交叉熵损失；对于 [0, 1] 范围内的指标，采用均方误差损失；对于 {0, 0.5, 1} 范围内的指标，采用交叉熵损失。同时，利用专家演示和模拟器反馈。对于强化学习阶段（IRL-VLA-RL），采用近端策略优化（PPO），其裁剪参数ε = 0.2，折扣因子γ = 0.99，广义优势估计（GAE）参数λ = 0.95。训练在8块NVIDIA A100 GPU上进行。

实验设置

数据集和指标。NAVSIM 是一个基于 OpenScene（nuPlan 的重新发布版本）构建的面向规划的自动驾驶数据集。它提供 8 个 1920×1080 摄像头和一个融合的 LiDAR 点云，该点云由 5 个传感器在当前帧和之前 3 个帧中聚合而成。该数据集分为 nav_train（1,192 个训练场景）和 nav_hard（136 个评估场景）。

NAVSIM 基准测试提供了一个非反应式模拟环境，并采用扩展预测驾驶员模型评分 (EPDMS) 作为其闭环规划指标。
