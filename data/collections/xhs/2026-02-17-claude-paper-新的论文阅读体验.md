# claude-paper：新的论文阅读体验

> 作者: @alaliqing | 👍 1400 | ⭐ 2384
> 来源: https://www.xiaohongshu.com/explore/69941762000000000e00d26d

---

做了一个 claude code 的 plugin，来帮助我系统性地阅读论文，又集成了一个 web library 来收录所有生成的论文学习资料，效率大幅提升。
	
skill 能力：
🍳 /claude-paper:study：自然语言可调用，开始论文学习
🍳 /claude-paper:webui：开启 library/阅读器
	
关键 feature：
⌲ claude code 的模型能力
⌲ web 集成阅读器
⌲ 本地存储生成的学习资料
⌲ 源代码一键跳转
⌲ vscode 一键打开
