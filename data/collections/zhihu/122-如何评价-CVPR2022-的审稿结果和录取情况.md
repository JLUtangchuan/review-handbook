2. 关键词

multi-view；LiDAR-based；panoptic segmentation；multi-task（3D object detection + panoptic segmentation）；BEV feature；RV（range-view） feature；center density heatmap

3. 动机
在LiDAR-based 3D目标检测框架中，大量点云是背景点，如果将这些点云不加任何线索（类似于语义标签等），一股脑的送到框架中，很难得到好的结果。从已有的一些工作（pointrcnn，STD，RSN等），赋予点云二分类标签或者语义标签，区分前背景点，可以获得更好的检测结果。因此，作者提出将panoptic segmentation作为辅助任务，指导BEV检测网络学习。
Many of these points represent the background region, including drivable surface, sidewalk, vegetation, etc. Feeding all this information to a 3D object detection algorithm without providing extra clues, such as semantic information, makes the recognition and localization process challenging.
we resort to 3D panoptic segmentation as an auxiliary task for guiding and further improving the performance of Bird’s-Eye-View (BEV) based 3D object detection algorithms.
不同view的信息存在shortcomings，充分利用不同view信息的优势，可以提升检测性能。
guiding a BEV-based detection model with features learned from a Range-View (RV) based network can reduce the sparsity of features representation in BEV projection
we supplement the BEV-based detection backbone with additional RV features extracted from the panoptic segmentation backbone, providing a rich set of multi-view information to aid the detection.

总结：

the augmented backbone features, foreground semantic labels, and the center density heatmap guide the detection head towards a more accurate 3D box recognition and localization.
4. 网络框架
Backbone

input：LiDAR 点云

output：panopticsegmentation + 3D object detection results

主要包括：multi-view backbone augmentation，class-wise foreground attention以及 center density heatmap modules.

具体而言：

对于panoptic segmentation任务，选用CPSeg框架；
对于3D object detection results任务，选用CenterPoint。

两个网络联合起来训练：

利用panoptic segmentation encoder的RV feature augment检测网络的backbone；
利用panoptic segmentation encoder预测的foreground semantic labels和instance box center offsets，指导2D backbone和检测头预测目标和其中心；
4.1 Multi-View Backbone Augmentation

该模块主要是利用不同view信息的优点，以boost性能，包括range-view和BEV。RV feature比较dense，便于检测小目标，但难以应对远距离目标、尺度变化和遮挡等目标；BEV避免了RV feature存在的问题，但是由于其sparse和coarse，也难以检测小目标。因此，作者通过weighting的方式，combine这两个view的特征。具体包括以下2个子模块：

Cascade RV Feature Fusion Module

先通过级联的方式融合2个view的特征。

Cascade RV Feature Fusion Module
Attention-based RV-BEV Feature Weighting Module

再通过channel attention + space attention的方式，weighting不同feature的重要性。

Attention-based RV-BEV Feature Weighting Module
4.2 Class-wise Foreground Attention Module

panoptic segmentation预测了RV plane每个点的语义信息，然而3D目标检测任务仅关心前景点。因此该模块将estimated probability maps作为输入，投影到BEV plane，然后建立class-wise attention，用于提升分类和定位精度。

4.3 Center Density Heatmap Module

该模块的目的是为检测头提供instance-level的信息，建立一个可能存在目标的中心的heatmap，以指导最终的检测头生成最终的预测结果。
