# 搭建一个daily读论文助手

> 作者: @Chip_Juicer | 👍 353 | ⭐ 534
> 来源: https://www.xiaohongshu.com/explore/6a16b45c000000003700d9d6

---

每天追论文太累[哭惹R]？用codex搓了一个自动更新论文的网站。github开源项目：Paper Daily
它可以每天自动帮你搜索和整理与你研究方向相关的最新论文[害羞R]，并生成中文技术总结[坏笑R]。
项目地址：走过路过🥺求个star🌟
https://github.com/Futuresxy/paper-daily
它适合这些人：
- 每天想看 arXiv 最新论文，但不想手动刷关键词的人[喝奶茶R]
- 想搭一个属于自己的论文雷达的人[哇R]
目前支持的能力：
- 每天自动定时搜索 arXiv 最新论文
- 按自己的研究方向筛选
- 自动生成论文链接和 PDF 链接
- 用 DeepSeek（便宜好用[赞R]） / OpenAI 生成中文创新点总结
- 给每篇论文标注匹配度：high / medium / low
- 支持 GitHub Pages 部署成个人网站
- 支持用 GitHub Issue 修改研究兴趣方向
- 完全开源，可以 Fork 后改成自己的论文日报
	
最终效果就是：
每天打开一个网页，就能看到和自己研究方向相关的新论文、创新点、匹配理由和原文链接。
不需要自己写后端，也不需要维护服务器。
GitHub Actions 负责每天自动跑，GitHub Pages 负责展示网页。
如果你也每天被论文淹没，可以试试这个项目：
https://github.com/Futuresxy/paper-daily
