# [大模型 41] 强化学习学推理分支，不学低熵 token 性能更优 Beyond the 80/20 Rule

> 作者: hzwer 黄哲威 | 来源: https://zhuanlan.zhihu.com/p/1913997943402401852

---

专栏上文：[大模型 40] 张祥雨访谈 多模态大模型研究的挣扎史和未来，下一篇：[大模型42] 后训练 SFT 的艰难探索 OpenThoughts3

刷 HuggingFace 的每日论文刷到的，《Beyond the 80/20 Rule: High-Entropy Minority Tokens Drive Effective Reinforcement Learning for LLM Reasoning》

太长不看：本文研究了在大型语言模型（LLM）的推理过程中，高熵少数派令牌（token）在强化学习（RL）中的作用。通过分析链式思维（CoT）推理中的 token 熵模式，研究发现只有一小部分 token 表现出高熵，这些 token 作为关键的分叉点，引导模型走向不同的推理路径。

摘要
通过强化学习与可验证奖励（RLVR）增强大型语言模型（LLM）的推理能力已成为一种强大的方法，但其机制尚未得到充分理解。在这项工作中，我们通过token熵模式这一新颖的视角，对RLVR进行了开创性的探索，全面分析了不同token如何影响推理性能。通过检查链式思维（CoT）推理中的token熵模式，我们观察到只有一小部分token表现出高熵，而这些token作为关键分叉点，引导模型走向不同的推理路径。此外，研究RLVR训练过程中熵模式的演变，发现RLVR很大程度上遵循了基模型的熵模式，主要调整了高熵token的熵。这些发现强调了高熵token（即分叉token）对RLVR的重要性。我们最终通过将策略梯度更新限制在分叉token上来改进RLVR，并发现了一个甚至超越80/20规则的发现：仅使用20%的token，在Qwen3-8B基模型上仍能实现与全梯度更新相比具有竞争力的性能，并在Qwen3-32B（+11.04的AIME’25和+7.71的AIME’24）和Qwen3-14B（+4.79的AIME’25和+5.21的AIME’24）基模型上显著超越全梯度更新，显示出强烈的扩展趋势。相比之下，仅对80%最低熵的token进行训练会导致明显的性能下降。这些发现表明，RLVR的有效性主要源于优化决定推理方向的高熵token。总体而言，我们的结果强调了通过token熵视角理解RLVR以及通过利用高熵少数token来进一步改进LLM推理来优化RLVR的潜力。

上一期祥雨老师访谈中说到：o1 的 RL 被很多人认为不是 RL，只是借用了一些名词和方法论。因为决策步非常多，奖励（环境反馈）极致稀疏而且难以估计。包括一些 RL 流行的 MCTS 或者 PRM 方法效果都不是很好（可能有各种原因）。一个最大的区别是大语言模型有预训练。如果是无预训练冷启动 RL，相当于生成每个词的每一步决策都有一个几万大小的动作空间，现有的 RL 算法其实无能为力。但是由于有了预训练，其实动作空间被极致压缩，对于一个几千 token 的数学题，其实关键的决策分支并不多，RL 只要解决这些关键的分支问题即可。

据说最近有类似发现的团队挺多，这个结论应该是靠谱的。

介绍

长链式思维的回答模式像是树搜索，分支点高熵，其它推理轨迹低熵

我们首先指出，在LLM的链式思维（CoT）过程中，熵分布表现出一种明显模式，其中大多数token以低熵生成，而一小部分关键token以高熵出现。通过比较这两部分token的文本含义，我们观察到平均熵最低的token主要完成了正在进行的语言结构，而平均熵最高的token作为关键决策点，决定了在多个潜在路径中的推理轨迹（称为分叉点）。除了定性分析外，我们通过在解码过程中人为地调整分叉token的熵来进行控制实验。定量结果显示，适度增加这些高熵分叉token的熵会导致推理性能的可衡量提升，而人为地降低它们的熵会导致性能下降，证实了保持高熵以及作为“分叉点”的这些高熵token的重要性。此外，通过分析RLVR训练过程中token熵的演变，我们发现推理模型很大程度上保留了基模型的熵模式，仅随着训练的进展逐渐发生相对较小的改变。此外，RLVR主要改变了高熵token的熵，而低熵token的熵仅在小范围内变化。上述观察结果突出了高熵少数token在CoT和RLVR训练中可能发挥的关键作用。

只学高熵甚至更好，可能说明学决策点更不容易过拟合？

基于对分叉token的发现，我们通过仅对20%最高熵的token进行策略梯度更新并屏蔽其余80%的梯度来进一步改进RLVR。我们观察到尽管仅使用20%的token，该方法在Qwen3-8B基模型上仍能实现与全梯度更新相比具有竞争力的推理性能。此外，其有效性随着模型规模的增加而提高，在Qwen3-32B基模型上产生了+11.04的AIME’25和+7.71的AIME’24推理改进，在Qwen3-14B基模型上产生了+4.79的AIME’25和+5.21的AIME’24推理改进，如图1（b）所示。值得注意的是，仅使用20%高熵token训练的32B模型在AIME’24上获得了63.5分，在AIME’25上获得了56.7分，为直接从参数少于600B的基模型训练的推理模型设定了新的最先进水平（SoTA）。将最大响应长度从20k扩展到29k进一步将我们的32B模型的AIME’24分数从63.5提升到68.1。相反，仅对80%最低熵的token进行训练会导致严重的性能下降。这些观察结果显示，20%的token实现了与100%相当或超过的性能，甚至超越了80/20规则。结果表明，作为推理轨迹中关键决策点的高熵少数token几乎占了RLVR中所有性能提升的原因。

而且作者发现对于更大的模型，筛选 token 学习的策略更有效。

最后，我们通过一系列消融研究探讨了为什么保留一小部分最高熵的token会导致RLVR中的强性能。通过调整所选择的分叉token的比例，无论是将其从20%降低到10%还是增加到50%或100%，并报告相应的推理指标和整个训练过程中的总体熵。实验结果表明，保留大约20%的最高熵token最优地平衡了探索和性能，而偏离20%会随着探索的减少而降低总体熵并导致更差的性能。这表明只有一小部分高熵token在RL期间有意义地贡献于探索，而其他token可能是中性的甚至是有害的。将比例降低到10%会移除某些有用的token，这会削弱探索。将比例增加到50%或100%会添加低熵token，这也会降低探索的有效性。最后但并非最不重要的是，保留前20%的高熵token会导致32B模型的最大性能提升，其次是14B模型，以及8B模型的最小提升。这可能是由于较小模型的容量不足，限制了其从增加的探索中受益的能力。这些发现突出了在RLVR中保留适当比例的高熵token的重要性。随着模型规模的增加，选择高熵token的策略似乎有效地扩展了。

总结：

在CoT中，大多数token生成的熵较低，而只有一小部分表现出高熵。这些高熵的少数token通常作为推理路径中的“分叉点”。
RLVR主要改变了高熵token的熵，而低熵token的熵仅在小范围内变化。这突出了高熵少数token在CoT和RLVR训练中的关键作用。
通过仅对20%最高熵的token进行策略梯度更新并屏蔽其余80%的梯度来改进RLVR，实现了与全梯度更新相比具有竞争力的推理性能，甚至超越了80/20规则。
保留大约20%的最高熵token最优地平衡了探索和性能，而偏离20%会随着探索的减少而降低总体熵并导致更差的性能。这表明只有一小部分高熵token在RL期间有意义地贡献于探索。

强化学习中的熵模式变化

通过分析RLVR训练过程中token熵的演变，我们发现推理模型很大程度上保留了基模型的熵模式，仅随着训练的进展逐渐发生相对较小的改变。具体来说，RLVR主要改变了高熵token的熵，而低熵token的熵仅在小范围内变化。

RL 训练过程中，和基础模型的高熵 token 重叠还是很大

这些观察结果进一步支持了高熵少数token在CoT和RLVR训练中的关键作用。它们作为推理路径中的“分叉点”，决定了模型走向不同的推理路径。在RLVR训练中，对这些高熵token的优化调整直接影响了模型的推理性能。

相比之下，低熵的多数token主要完成了正在进行的语言结构，它们的变化对整体推理性能的影响较小。这表明在RLVR中，针对高熵token的策略优化比对所有token的全面优化更为有效。

这一发现为我们提供了一个新的视角，即通过关注和优化高熵token来改进RLVR算法，从而更有效地提升LLM的推理能力。

讨论

讨论1：高熵少数token（即分叉token）可能在解释为什么RL泛化而SFT记忆方面发挥关键作用。Chu等人（2025）经验性地表明，RL，特别是基于结果的奖励，对未见、基于规则的任务表现出强烈的泛化能力，而监督微调（SFT）倾向于记忆训练数据并在训练分布之外的泛化方面挣扎。我们假设，RL和SFT不同的泛化能力的一个关键因素可能与分叉token中的熵有关。我们的实验（例如，图5和图7）表明，RL倾向于保留甚至增加分叉token的熵，保持推理路径的灵活性。相比之下，SFT推动输出对数朝向one-hot分布，导致分叉token中的熵减少，并因此失去了推理路径的灵活性。这种灵活性可能是一个推理模型能够有效地泛化到未见任务的关键决定因素。

讨论2：与传统RL不同，LLM推理整合了先验知识并必须产生可读的输出。因此，LLM CoT包含低熵多数token和高熵少数token的混合，而传统RL可以假设在整个轨迹中具有统一的行动熵。如图2（a）所示，大多数LLM CoT token具有低熵，只有一小部分表现出高熵。相比之下，传统RL通常将每个行动分布表述为具有预定标准偏差的高斯分布（Schulman等人，2017；Raffin等人，2021；Weng等人，2022），导致行动之间的统一熵。我们将LLM CoT中这种独特的熵模式归因于它们在大规模先验知识上的预训练以及对语言流畅性的需求。这迫使大多数token与记忆的语言结构保持一致，产生低熵。只有一小部分在预训练语料库中本质上不确定的token允许进行探索，并因此表现出高熵。这一推断与我们在表1中的结果一致。

讨论3：在RLVR中，熵奖励可能次优，因为它增加了低熵多数token的熵。相比之下，clip-higher有效地促进了高熵少数token中的熵。在RL中，熵奖励通常被添加到训练损失中，通过增加行动的熵来鼓励探索——这是在传统任务中已确立的做法（Schulman等人，2017；Williams，1992；Mnih等人，2016），并且最近应用于LLM推理（Sheng等人，2024；Hu等人，2024）。然而，如上所述，与典型的RL轨迹不同，LLM CoT表现出独特的熵模式。增加所有token的熵可能会通过扰乱低熵多数而导致性能下降，而选择性地增加高熵少数token的熵会提高性能（图3）。因此，统一应用的熵奖励对于CoT推理来说是次优的。相反，clip-higher（Yu等人，2025），它适度地提高了方程（4）中的ϵhigh，更好地瞄准了高熵token。经验上，我们观察到具有高重要性比率rt(θ)（如方程（2）中所定义）的token倾向于具有更高的熵。通过在训练中包含更多的这些token，clip-higher增加了总体熵而没有显著影响低熵token，如Yu等人（2025）所支持并在图5中所示。

作者总结（来自朋友圈）：
我们基于一个非常简单的改动（在LLM RL训练中丢弃80%的low-entropy tokens的policy gradient），在32B模型上取得了AIME'24上63.5，AIME'25上56.7的zero RL的SoTA表现（20k max response length）。如果将max response length增大到29k继续训练，则甚至可以在AIME'24上达到68.1。 我们发现了LLM RL过程中一些比较神奇的现象： CoTs中只有少量的tokens是high-entropy的，大多数tokens都是low-entropy的。少量high-entropy tokens发挥着reasoning path中"forks"的作用，决定了reasoning的方向；大量的low-entropy tokens更倾向于在既定的方向下完成reasoning。并且，这些high-entropy tokens的high entropy性质在CoT中是必不可少的，打压他们的entropy会导致明显性能下降。 在LLM上做RL并不会显著改变base model的entropy patterns，RL之后的模型和base模型在决定哪些tokens应该high-entropy的重合度非常高。此外，在RL训练中，基本上只有high-entropy的tokens的entropy会被显著改变，low-entropy tokens的entropy变化很小。 LLM RL可能主要只在学high-entropy tokens。我们做了一个非常大胆的尝试，基于DAPO算法，在RL训练中只留下每个batch里entropy最高的20%的tokens的policy gradient、丢弃其余80%的policy gradients，发现在Qwen3-8B上不会掉点，在Qwen3-14B和Qwen3-32B上甚至能大幅度涨点。具体地，相较于DAPO，在Qwen3-32B上，+11.04 on AIME'24 and +7.71 on AIME'25；在Qwen3-14B上，+4.79 on AIME'24 and +5.21 on AIME'25。体现出了很好的随着模型增大、performance improvement越大的scaling性质。 基于上述insights，我们进一步讨论了： (1) 对于为什么RL generalizes，SFT memorizes的可能解释； (2) prior knowledge和可读性要求可能是导致LLM CoTs的entropy patterns如此特殊的原因； (3) 从token entropy角度分析，clip-higher可能比entropy bonus更优。
