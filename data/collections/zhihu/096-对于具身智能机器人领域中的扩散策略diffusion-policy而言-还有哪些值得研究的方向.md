谢邀~扩散策略（Diffusion Policy）在近两年取得了显著进展，其强大的表征建模能力不仅为机器人控制领域带来了革命性的突破，扩散模型在其他领域的成功还给了相关研究社区构建大规模具身智能基础模型的希望和动力。在这一背景下，一系列数据集和通用模型的探索工作相继展开，旨在标准化和统一化具身智能中的诸多难题。具体来说，本文将概述机器人控制基础动作模型的技术前沿，并进一步介绍近期公开的强大模型《RDT-1B: a Diffusion Foundation Model for Bimanual Manipulation》。该模型作为扩散策略在双臂操作领域的代表性成果，展现了其在复杂任务中的卓越性能，为具身智能的发展提供了重要的技术支持。

1. 引言

近年来，随着扩散模型理论的日益成熟，基于该模型的应用在多个领域迅速发展。在机器人技术领域，扩散模型因其高效的生成能力，被视为实现通用机器人的重要工具。理想的机器人模型应具备高度的泛化能力，能够在不同场景中操作各种物体，并适应多种任务。然而，目前大多数研究仍然集中在特定机器人的简单任务上，使用的数据集规模较小，模型的参数量也相对有限。类似于其他生成式模型领域，能否通过基于Transformer的强大建模能力，开发一个通用的大模型来应对机器人操作中的多样化任务，成为了值得探索的方向。本文主要介绍的工作源自论文《RDT-1B: a Diffusion Foundation Model for Bimanual Manipulation》。


图 1：VoxAct-B 是一种基于语言和 voxel 方法的视觉语言模型 [2]。

在许多人类环境中的任务都需要双手操作，因此，双手协作在机器人技术研究中已成为热点之一[1,2,3]。协调两个机械臂的动作引入了更为复杂的动作空间，增加了动作建模的难度，因此开发这类基础模型具有相当大的挑战性[4,5,6]。此外，由于机器人设备的高昂成本，模型训练也面临着训练数据稀缺的限制。为了缓解数据不足的问题，国际多团队合作收集的机器人数据集，如Open X-Embodiment[7]，为这一难题提供了有效的解决方案。


图 2：PerAct2 是一种语言作为条件输入的双手操作智能体 [6]。

此外，为了更好地与人类认知对齐，需要将自然语言响应与机器人动作整合成一个端到端模型，这类模型称为视觉语言动作模型（Vision-Language-Action Models, VLA）。

2. 机器人基础动作模型的技术前沿

机器人基础动作模型的发展可以视为视觉语言模型和机器人动作学习这两条研究轨道的结合。

2.1 视觉语言模型


视觉语言动作模型可以被视为一种特殊输出形式的视觉语言模型（VLM）。在视觉语言模型方面已有许多前沿研究[8,9]，并在分类、检测、分割等下游任务中表现良好。这类模型通常关注于视觉问答（VQA）、图像描述等任务。这些任务与机器人决策中的逻辑推理需求密切相关，因此视觉语言模型的进步将极大影响机器人基础模型的发展。


图 3：PaLM-E 具身智能 VLM 模型工作流程示意图 [9]。

以上图中的视觉语言模型为例，PaLM-E 是一个通用的多模态语言模型，适用于具身推理任务、视觉-语言任务和语言任务。它将视觉-语言领域的知识迁移到具身推理中——从复杂动态和物理约束的环境中的机器人规划，到回答关于可观察世界的问题。PaLM-E 处理多模态输入，即在一个序列中，将来自不同模态的输入（如图像、神经3D表示或状态，标记为绿色和蓝色）与文本 token（标记为橙色）一起作为输入，进行端到端训练。PaLM-E 能够输出用于下游机器人控制的指令。


2.2 机器人动作学习

机器人动作模型直接输出动作控制信息，因此如何生成这部分信息是研究的核心。一种有效方法是使用大规模多样化的数据进行训练[10]，这样可以让模型的动作空间泛化，处理各种新物品的交互[11]，并实现控制技巧与新物品之间的灵活组合[12]，同时具备解决通用任务目标和指令的能力[13,14,15]。


图 4：Google Deepmind 开发的开放世界控制模型 Manipulation of Open-World Objects (MOO) [14]。


MOO架构的主要目的是在任务执行过程中，有效传递特定物体的信息。首先，在每个回合的第一帧中，通过目标检测模型（如 Owl-ViT）提取物体位置，并用边界框的中心表示。接着，将生成的分割掩码与每帧的输入图像通道拼接，使模型在处理每帧时都能获取明确的物体实例信息。此外，语言嵌入仅保留任务相关信息，确保物体的特定信息通过物体实例掩码传递。

上图中显示，指令被编码后，与当前帧图像和近期历史帧一起输入到 FiLM EfficientNet，然后通过 Token Learner 进一步处理，选择关键特征并送入 Transformer 进行推理，最终生成动作输出。这种设计使模型能够专注于目标物体的位置信息，通过多模态输入融合实现精准任务执行。

机器人基础模型的训练类似于其他领域的大模型训练，遵循“预训练-精调”的范式。著名的工作包括 OpenVLA[16]、Octo[17] 和 Google DeepMind 的 RT-2 (Robotics Transformer 2)[18]。RT-2 将基于互联网规模数据训练的视觉语言模型直接整合到端到端机器人控制中，显著提高了对新物体的泛化能力，并能理解训练数据中不存在的指令。


图 5：OpenVLA 模型工作流程示意图 [16]。


OpenVLA 是一个拥有 70 亿参数的开源视觉-语言-动作（VLA）模型，专为通用机器人操作设计。该模型使用来自 Open X-Embodiment 数据集的 97 万个机器人操作回合的大规模训练数据，通过结合视觉和语言输入与机器人控制任务，实现多机器人控制和高效微调。

上图展示了 OpenVLA 的工作原理：首先从数据集中获取大量训练数据，然后基于基础视觉-语言模型（Base VLM）进行微调，包括 Llama 2（7B 参数）和 ViT（视觉 Transformer），以便理解视觉输入（如图像）和语言指令，并将其转换为机器人动作。

在实际应用中，用户可以通过自然语言指令（如“擦桌子”）给机器人下达任务，OpenVLA 根据这些指令生成相应的控制信号，如位置变化、角度变化和夹爪调整，实现闭环控制。此外，OpenVLA 支持多种机器人的控制，并能通过参数高效微调快速适应新任务场景，展现出高度灵活性。

作为一个完全开源的项目，OpenVLA 提供数据、模型权重和代码，研究人员和开发者可以在 Hugging Face 上下载并微调其模型权重和 PyTorch 训练管道，广泛应用于不同的机器人控制场景。


图 6：RT-2 模型工作流程示意图 [18]。

RT-2 是一种将机器人动作表示为“另一种语言”的视觉-语言-动作模型，通过将动作转换为文本 token ，与大规模互联网视觉-语言数据集一同训练，实现闭环机器人控制。在推理过程中，这些文本 token 被解码为机器人动作，使机器人能够执行特定任务。RT-2 利用视觉-语言模型的预训练优势，将其通用化、语义理解和推理能力转移到机器人控制中。

上图展示了 RT-2 的工作流程：通过视觉问答（VQA）数据和机器人动作数据进行联合训练，模型结合视觉输入生成动作指令（如位移和旋转），从而执行任务，如“将草莓放入正确的碗中”或“选择快要掉落的袋子”。相比 OpenVLA，RT-2 的独特之处在于直接将机器人动作视为语言的一部分，融合了语言和动作的表示方法，而 OpenVLA 更注重通过微调视觉-语言模型来实现机器人控制，并支持多机器人任务。RT-2 的方法将机器人动作编码为文本 token ，使其能更直接利用视觉-语言模型的语义理解能力，提升了模型在复杂任务中的推理表现。


3. 基于扩散模型的机器人基础模型


近期，基于扩散模型 DiT [19] 架构的机器人基础模型 Robotics Diffusion Transformer 被提出 [20]。RDT 模型的训练分为两个部分。首先，在广泛的多机器人数据集上进行预训练，使其成为多任务“通才”模型。扩大数据规模有助于其从其他机器人的数据集中学习可迁移的物理知识。实现这种有效泛化的关键在于设计一个具有强大表达能力的通用基础模型，能够从大量机器人数据集中学习多种形式的信息。由于机器人领域的数据结构复杂，输入和输出形式多样，模型需要具备高度的可扩展性。然后，为了在特定任务上达成最佳表现，RDT 在目标双臂机器人上收集的小数据集上进行微调。


图 7：Robotics Diffusion Transformer 模型、训练数据与任务部署示意图。

3.1 机器人与任务介绍

RDT 模型的控制对象是一个 ALOHA 双臂机器人 [21]，该机器人由两个带夹持器的手臂和三个摄像头组成，具有高度复杂的控制模态，如下图所示：



图 8：ALOHA 双臂机器人与动作模态示意图。

机器人控制任务主要有以下难点：

多峰 (multimodal) 的动作分布

机器人在尝试抓住立方体时，有多种动作模态可以完成任务。单手操作只能控制一个机械臂，人类操作员在演示时可能随机选择其中一种动作，导致收集到的动作数据具有多模态性。OpenVLA 和 RT-2 在这类任务上表现不佳，因为它们无法有效建模这些多模态的动作数据。

数据异质性

不同机器人的物理结构和动作空间可能差异很大，开源数据集中包含来自不同来源机器人的数据。这些差异导致数据异质性，可能在训练期间降低模型能力并阻碍策略泛化。当前方法通常直接丢弃不同动作空间的机器人数据或仅保留结构恒定的数据部分，这会浪费宝贵数据。

非线性的物理状态

机器人数据中许多物理量受非线性动力学方程控制，物理对象间的相互作用（如碰撞或约束）可能导致物理量高频变化。此外，这些物理量的数值范围可能不稳定（如传感器不可靠导致的极端值），这些因素对模型训练构成挑战。

综上所述，机器人基础模型会面临两个核心的问题：

如何设计通用的模型架构来解决数据多模态问题
如何设计模型来解决数据异质性问题




3.2 核心方法


为了应对机器人动作数据的多模态特性，RDT 相比以往的工作进行了几项核心技术设计：


采用 Diffusion Transformer（DiT）的技术路线，使用类似 DiT 网络的设计作为模型的骨架。通过利用扩散模型强大的分布建模能力和丰富的模型容量来解决上述问题。
为了解决数据异质性，RDT 精心设计了多模态编码，以消除各种模态的差异性。对原始 DiT 结构进行了多项改进，包括解码器和正则化，并使用交替条件注入（Alternating Condition Injection, ACI）技巧。
为了在异构数据上进一步训练 RDT，提出了一种物理可解释的统一动作空间（Physically Interpretable Unified Action Space）。这种创新格式适用于各种带夹持臂的机器人，减轻了不同机器人之间的潜在冲突，同时保留了原始动作的物理含义，从而促进模型学习具有跨不同机器人数据集的可泛化物理知识。这个动作空间中的各个数据格式可以准确定义具体的物理量，如下表所示：
表 1：RDT 统一的动作空间格式定义。

每个位置都有明确的物理含义，对于缺失的数据，RDT 会进行填充。这个统一的动作空间可以对几乎所有带夹臂机器人的数据进行预训练，大大扩展数据规模以满足基础模型的需求。

扩散模型设计

RDT 是目前最大的机器人预训练模型。它在大量机器人数据集上进行预训练，然后在 6000 多条双臂机器人数据上精调，使其在一系列极具挑战性的任务中表现出色，远超当前的双臂机器人模型。
该模型的输入信息包括语言指令 l ，观测信息 o_t 。其中观测信息 o_t 具体包括了 T_{\mathrm{img}} 帧的历史图像信息 X_{t-T_{\mathrm{img}}+1:t+1} ， 机器人的本体感知信息 z_t ，比如位置、速度等物理量的低维向量输入，控制信号频率 c ，即动作信号输出的频率。语言指令由一些基本单词构成，包括动作名，对象名，环境名以及一些额外条件，比如 “pick the bottle with the left hand”。
RDT 建模动作在语言指令和观测信息条件下的动作分布，即 p(a_t|l,o_t) 。此外为了增强动作本身的一致性，减少因为多次推断而产生的累计误差，在生成时会输出一段动作序列，即 p(a_{t:t+T_a}|l,o_t) 。


图 9：RDT 模型框架示意图




RDT 神经网络整体基于 DiT 架构。对于 RDT-1B，其主干网络由 28 层、32 头的 DiT 组成，隐藏层大小为 2048，总参数量为 12 亿。

特征编码

数据异质性主要体现在两个层次：不同模态之间和相同模态内部。
首先，不同模态的数据在信息量、格式和维度上存在显著差异。因此，模型针对不同输入设计了特定的编码，并将这些模态编码到统一的潜在空间中。

低维物理信息数据编码

对于表示位置、速度等物理量的低维向量输入，模型借鉴了《Fourier features let networks learn high frequency functions in low dimensional domains》[22] 的思路，使用傅里叶特征的 MLP 进行编码。这是因为傅里叶特征映射可以使基于坐标的 MLP 更适合在低维度上建模函数，通过大量实验表明，调整傅里叶特征参数可以显著提高一系列图形和成像任务的性能。

图像编码

为了从高维图像中提取紧凑的信息，模型采用了预训练的视觉编码器 SigLIP [23]来对齐图像和文本，并在训练期间固定其权重以节省 GPU 内存。

语言编码

模型使用基于 Transformer 的语言模型 T5-XXL [24] 来处理长度不一的抽象语言信息，并在训练期间固定权重以节省 GPU 内存。
其次，同一模态内不同时刻的数据输入信息量可能差异很大，可能导致模型过于关注局部细节而失去整体感知。为此，RDT 模型在编码时以一定概率随机独立地掩盖每个多模态输入，以防止模型过度依赖某一特定输入信息。



正则化设计


在 Attention 网络中使用 QKNorm 防止数值溢出。
受到《UnitNorm: Rethinking Normalization for Transformers in Time Series》[25] 的启发，将 LayerNorm 替换为 RMSNorm。LayerNorm 的 centering 处理不适合时序模型的数值含义，会导致 token 偏移。

在代码中的实践方式如下：

from timm.models.vision_transformer import Attention, Mlp, RmsNorm, use_fused_attn
attn = Attention(
    dim=hidden_size, num_heads=num_heads, 
    qkv_bias=True, qk_norm=True, 
    norm_layer=RmsNorm,**block_kwargs)

如果不采用这些正则化方法，训练过程可能在中间阶段崩溃，如下图所示：


图 10：不使用 QKNorm 与 RMSNorm 方法的 RDT 训练损失图。


非线性动作输出设计

机器人的动作输出通常是非线性的。RDT 用非线性 MLP 解码器替换了 Transformer 网络的线性解码器，将隐变量投影到物理空间中。这样可以有效捕捉非线性动力学关系，有助于完成精细操作的复杂任务。


交替条件注入 (Alternating Condition Injection, ACI) 技巧

与传统 DiT 架构中用于生成图片的标签性质不同，由于图像和语言输入都是高维或可变长度的复杂变量，不宜简单地使用传统的 LayerNorm 处理。RDT 模型采用交叉注意力层来减少信息损失。此外，由于图像信息相比文本信息会占用更多的 token 长度，直接使用所有模态信息会导致图像信息过度影响模型。为解决此问题，多层交叉注意力中，文本和图像信息交替注入，而不是让每一层都处理所有模态信息。

在代码中，可以按以下方式实践：

# Forward pass
conds = [lang_c, img_c]
masks = [lang_mask, img_mask]
for i, block in enumerate(self.blocks):
      c, mask = conds[i%2], masks[i%2]
      x = block(x, c, mask)
4. 实验部分
4.1 训练数据

总训练数据集多达 46 个，各类数据超过 100 万条轨迹，包括 RT-1、DROID、RH20T 等著名数据集，精调数据集使用了 Mobile ALOHA 数据集。
为确保不同数据集的数据具有相同的意义，RDT 统一了各个变量的物理单位（如 m、rad、m/s、rad/s 等），粗略调整数据集的尺度，而不是严格归一化为 [−1, 1] 或 N (0, 1)。

此外，大规模预训练后的大量参数提供了大量的先验知识，这大大提高了泛化性。以 Wash Cup 和 Pour Water 任务为例，RDT 可以零样本推广到未见过的物体、场景和模态，并在未见过的场景上仍然可以实现较高的成功率，其性能与见过的场景没有太大差别。相比之下，其他基线甚至无法完成整个任务。以 Handover 任务为例，RDT仅用少量的样本就能学习交接和折叠等新的复杂技能，这些技能的动作模式与已知技能有很大的不同，而其他技能的成功率几乎为零。此外，RDT 可以处理灵巧的任务。以 Robot Dog 任务为例，RDT 可以精确控制推动操纵杆时的角度，而其他一些因素则导致机器狗偏离。这是因为扩散模型可以对多模态和非线性动作的分布进行建模，从而使动作精度满足灵巧任务的要求。

5. 总结


总的来说，RDT 作为成功的基于扩散模型的机器人基础模型，再次证明生成式模型可以成为具身智能领域的核心技术基石。这项研究表明，通过设计合适的数据格式、合理的模型架构，并应用足够规模的数据进行生成式模型训练，采用经典的“预训练-微调”范式，可以取得优异的结果。基于这一技术的潜力和愿景，能够与真实世界合理交互的生成式模型可能即将到来。
